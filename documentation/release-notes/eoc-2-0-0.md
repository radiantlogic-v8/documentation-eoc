# Environment Operations Center September 2026 Release Notes

September 2026

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v2.0.0.

These release notes contain the following sections:

[Highlights](#highlights)

[New Features](#new-features)

[Improvements to Existing Features](#improvements-to-existing-features)

[Bug Fixes](#bug-fixes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)

## Highlights

The latest version of Environment Operations Center adds new capabilities for managing tenants, infrastructure, environments, applications, and operations, including multi-tenant management, infrastructure management, environment tiers, ephemeral environments, scheduled application start and stop, centralized alerts and notifications, application endpoint management, additional storage request options for applications, promotion pipeline improvements, integrated customer support, and application and environment management improvements.

## New Features

- [CUI-2170, CUI-2172, CUI-2173, CUI-2177, CUI-2380, CUI-2398, CUI-2490]: Added multi-tenant management support, enabling multiple organizations within a single EOC deployment with organization-based access, role administration, and tenant-level feature controls.

- [CUI-2323, CUI-2371, CUI-2374, CUI-2375, CUI-2425, CUI-2426, CUI-2610, CUI-2629]: Added infrastructure management capabilities including registration, enable/disable, deletion, cloud-provider account visibility, and improved infrastructure selection across tenants.

- [CUI-2665, CUI-2667, CUI-2668, CUI-2669, CUI-2817, CUI-3140, CUI-3159]: Added configurable environment tiers for capacity, resource sizing, and application availability, with cloning, automated provisioning, governance controls, usage visibility, and tier upgrade and AWS scaling options.

- [CUI-2480, CUI-3029, CUI-3039, CUI-3040, CUI-3041, CUI-3043, CUI-3051, CUI-3084, CUI-3085]: Added ephemeral environments with configurable expiration dates, automatic cleanup, expiration extension, enable/disable controls, cleanup failure notifications, and promotion pipeline safeguards.

- [CUI-3052, CUI-3053, CUI-3061, CUI-3073, CUI-3074, CUI-3075, CUI-3083, CUI-3107]: Added scheduled application start and stop with recurring schedule support, cancellation and retry options, next-run timing information, and visibility into scheduled task execution.

- [CUI-1902, CUI-3128, CUI-3289]: Added default alert policies for applications and organizations and introduced a centralized Notification Center with improved routing and display.

- [CUI-3295]: Added Grid view for application endpoints with confirmation dialogs for enable/disable actions.

- [CUI-3177, CUI-3197, CUI-3207, CUI-3262]: Added Additional Storage for Identity Data Management and Identity Observability applications with file upload/download support, shared file management, storage configuration visibility, pre-enable validation, and cleanup on deletion.

- [CUI-3236, CUI-3216]: Added Portal API and MCP Server deployment options for IDO applications.

- [CUI-2863, CUI-2864, CUI-2865, CUI-2867, CUI-2869, CUI-2982, CUI-2987, CUI-3006]: Integrated Chatwoot into EOC for customer support with an AI assistant, knowledge retrieval, human agent handover with conversation history, support notifications, and predefined question templates.

- [CUI-3045, CUI-3046, CUI-3047, CUI-3048, CUI-3049, CUI-3050]: Added expanded API token management allowing up to five tokens per user, with creation, regeneration, usage tracking, disabled-token access restrictions, and automatic invalidation on user deletion.

## Improvements to Existing Features

- [CUI-2398, CUI-2406, CUI-2570, CUI-2577, CUI-2585]: Improved multi-tenant user experience including organization switching, login page refactoring, environment naming scoping, and organization-aware reports and settings display.

- [CUI-2586, CUI-2590, CUI-2591, CUI-2592, CUI-3036, CUI-3290]: Improved infrastructure and SDC management with multi-cluster SDC group support, centralized APIs, tenant isolation through ArgoCD projects, and an onboarding wizard for tenants and infrastructures.

- [CUI-2651, CUI-2652, CUI-2654, CUI-3107]: Improved scheduling logic with accurate cron expression generation, minute handling, and next-run calculation for recurring and one-time schedules.

- [CUI-2745, CUI-2776, CUI-2777, CUI-3128, CUI-3136, CUI-3169]: Improved alert management including pause/resume, role-aware visibility, status refresh, history accuracy, and SDC group name display in alerts.

- [CUI-2469, CUI-3130, CUI-3174, CUI-3180, CUI-3196, CUI-3289]: Improved notification emails and Notification Center routing, styling, and interaction consistency.

- [CUI-2662, CUI-2684, CUI-3175, CUI-3261]: Improved application endpoint health checks, status visibility across infrastructures, and endpoint information for remote environments.

- [CUI-2350, CUI-2968, CUI-2969, CUI-3068, CUI-3069, CUI-3225]: Improved application and environment management including cleanup, backup generation and retention for IDA and IDO across remote infrastructures, and storage cleanup on deletion.

- [CUI-2801, CUI-3108, CUI-3109, CUI-3122, CUI-3163, CUI-3237, CUI-3241]: Improved promotion pipelines with pre-publish safeguards, minimum version enforcement, pipeline cloning and deletion, infrastructure selection, and version compatibility checks.

- [CUI-2791, CUI-2895, CUI-3017, CUI-3059, CUI-3079, CUI-3082, CUI-3124, CUI-3185, CUI-3203]: Improved general UI including dashboard views, utilization charts, application settings, endpoint display alignment, error messages, last-visited-page behavior, and dropdown controls.

- [CUI-3292]: Added automated version update checks via scheduled cron jobs for application version management.
