# Environment Operations Center May 2025 Release Notes

May 9, 2025

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v1.3.1 and Secure Data Connector service v1.2.1.

These release notes contain the following sections:

[New Features](#new-features)

[Improvements](#improvements)

[Bug Fixes](#Bug-fixes)

[Security Vulnerability Fixes](#security-vulnerability-fixes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)

## New Features

- [CUI-2034]: Added default alerts for expiring and expired Secure Data Connector (SDC) tokens, as well as status changes.

- [CUI-2092, 2261]: Enabled alerts to be configured by the user for Secure Data Connectors.

- [CUI-2159]: Enabled log download to be filtered by time period (for Identity Data Management applications versions starting with 8.1.4).


## Improvements

- [AG-628]: Streamlined active connections metrics and token expiration time metrics by pulling them from DB for consistency.

- [AG-629]: Improvement to show SDC client status as a metric with consistent refresh every 15 seconds.

- [AG-637]: API endpoints of Agent and Group are updated to return Created and Last Modified Date timestamps in their GET responses.

- [CUI-2035]: Improvement to display the status of expiring and expired SDC tokens.

- [CUI-2099]: Added ability to start, stop, and restart all applications within an environment simultaneously.

- [CUI-2127, CUI-2268, CUI-2285, CUI-2286]: Improvement to display the SDC service version, creation date, and last modified date in the Environment Operations Center.

- [CUI-2166]: Improvement to scheduled maintenance email template.

- [CUI-2198, CT-1224]: Added ability to generate a new random password during Identity Analytics application creation.

- [CUI-2217]: Improvement to performance related to loading statistics and statuses.

- [CUI-2229]: Added a refresh button to the Events tab in the Admin section.

- [CUI-2230]: Improvement to alert and metrics labeling.

- [CUI-2232]: Improvement to UI, renamed "change password" to "reset password" and disabled the "reset password" option when Identity Data Management application is offline.

- [CUI-2234]: Added toggle feature for application endpoints on the application overview page.

- [CUI-2243]: Improvement to scheduled maintenance email notification to use the timezone related to the region.



## Bug Fixes

- [AG-627]: Fixed version format check on update agent API endpoint.

- [CUI-2199]: Fixed an issue with 503 error when an internal service was down.

- [CUI-2205]: Fixed an issue with backup retention configuration.

- [CUI-2216]: Fixed an issue with scheduled backup notifications accumulating when not acknowledged by the user.

- [CUI-2224]: Fixed an issue with unexplained errors.

- [CUI-2225]: Fixed an issue with Grafana alerts not working as expected.

- [CUI-2228]: Fixed an issue with description updates disappearing.

- [CUI-2248]: Fixed an issue with Settings section disappearing when navigating from Applications to the Admin section.

- [CUI-2250]: Fixed an issue with data sources not getting deleted from SDC connectors when the Identity Data Management application is deleted.

- [CUI-2257]: Fixed an issue with EOC alerts being blocked in firing state when Grafana rule has an error.

- [CUI-2260, CUI-2134]: Fixed an issue with pause and edit functionalities not working for the SDC while it is active.

- [CUI-2262]: Fixed an issue on Logs tab where clicking browser refresh resulted in an error.

- [CUI-2274]: Fixed an issue with the display of the Admin section to Environment Creator and User roles.

- [CUI-2279]: Fixed an issue where deletion of a Secure Data Connector resulted in an unexpected error.


## Security Vulnerability Fixes

- [Internal]: Updated the path-to-regexp library version 0.1.10 with version 0.1.12 to address CVE-2024-52798.

- [Internal]: Updated the axios library version 1.7.8 with version 1.8.2 to address CVE-2025-27152.

- [Internal]: Updated the @babel/helpers library from version 7.24.6 and 7.26.0 with version 7.27.0 to address CVE-2025-27789.
