# Environment Operations Center May 2026 Release Notes

May 5, 2026

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v1.5.2.

These release notes contain the following sections:

[Improvements](#improvements)

[Bug Fixes](#bug-fixes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)

## Improvements

- [CUI-3116]: Improvement to add an option to run EOC in read-only mode, allowing users to view data without making changes during EOC migration and scheduled maintenance.

- [CUI-3122]: Improvement to enable more granular Configuration Promotion Pipelines.

- [CUI-3152]: Improvement to add a Press Enter hint for the Recipient Email field.

- [CUI-3158]: Improvement to the UI for Report settings.

## Bug Fixes

- [CUI-3120]: Fixed an issue with the environment variable for IDO/IDA dashboards.

- [CUI-3138]: Fixed an issue where users were unable to log in to the IDDM application with the provided password. Users can now create passwords using special characters, excluding the following: ' " / \\ € £ ; : &. Users are now required to meet all password criteria before confirming their password, and appropriate warning messages are displayed in case of mismatches.

- [CUI-3146]: Fixed an issue where the reset password email always showed the default link expiration of 20 minutes, even when a custom value was set through `FORGOT_LINK_EXPIRATION`. The email now displays the actual configured expiration value.

- [CUI-3154]: Fixed an issue with report generation.

- [CUI-3155]: Fixed inconsistencies in Report settings.

- [SQ-1326]: Fixed an issue where the OIDC Redirect URL shown in the EOC UI did not match the actual hostname used in the Okta authorize redirect. Users can now log in to EOC using Okta OIDC provider authentication.

- [SQ-1327]: Fixed an issue where users could not view the Client ID and Client Secret values when selecting Edit for OIDC. Users can now view the Client ID and the last 6 characters of the Client Secret; the Client Secret remains non-editable once set.


For known issues reported after the release, please see the Radiant Logic Knowledge Base:
