# Environment Operations Center June 2025 Release Notes

June 2, 2025

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v1.3.2: 

These release notes contain the following sections:

[Improvements](#improvements)

[Bug Fixes](#Bug-fixes)

[Security Vulnerability Fixes](#security-vulnerability-fixes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)

## Improvements
- [CUI-1748]: Improvement to add tooltip descriptions when hovering over metrics during Alerts creation.

- [CUI-1934]: Improvement to display actions and associated status when a task is triggered, as well as the time taken to complete each action.

- [CUI-2201, SQ-266, SQ-304]: Improvement to allow users to configure email addresses for maintenance notifications. The user will be able to choose email integration already defined in the Integration section of the Admin tab.

- [CUI-2282]: Improvement to welcome emails to Environment Operations Center to be more user-friendly and contain a secure password reset link (for local users) for easier and more secure onboarding.

- [CUI-2295, CUI-2303]: Improvement to filter the metrics the user sees to be relevant to the application for which they are configuring Alerts.

- [CUI-2300]: Improvements to Task logs including pagination and search functionalities.

- [CUI-2301]: Improvement to display a warning when deleting a Secure Data Connector (SDC) if Identity Data Management (IDDM) data sources are using that SDC.

- [CUI-2305]: Improvement to add a tooltip for the Alert states (Normal, Firing, Pending, etc.) to make the Alert history is easily understood by users.

- [CUI-2306]: Improvement to Integrations setup to make it more user-friendly. 

- [CUI-2309]: Improvement to Alerts creation to warn the user of missing input.

- [CUI-2316]: Improvement to make the Secure Data Connector filter available on the Overview page.

- [CUI-2325]: Improvement to implement user-friendly metrics/alert selection with pre-configured alerts templates for Secure Data Connector and Identity Data Management.

- [CUI-2326]: Improvement to token expiration message.

- [CUI-2328]: Improvement to error message in event of manual update failure, and change in behavior to not update the last refresh timestamp when the request fails.

- [CUI-2344]: Improvement to add feedback link at the bottom of the EOC page so users can log feedback.

- [CUI-2352]: Improvement to the "forgot password" workflow.

## Bug Fixes

- [CUI-2272, CUI-2385]: Blocked users from naming Environments with common EOC terms. 

- [CUI-2276]: Fixed an issue with the "delete Application" option being disabled.

- [CUI-2288]: Fixed an issue where updates to SDC Group Name were not also updating the SDC Default Alerts description.

- [CUI-2292]: Fixed an issue with Alert Name not being updated in the Grafana dashboard.

- [CUI-2307]: Fixed broken link in the Test Integration setup email.

- [CUI-2310, QT-73]: Fixed an issue with inconsistency in the refresh functionality.

- [CUI-2314]: Fixed an issue with inconsistency with the pagination of version management.

- [CUI-2322]: Fixed an issue with incorrect error messages being displayed when invalid values were passed for integrations.

- [CUI-2332]: Fixed an issue where an attempt to selete data connector from Alerts page resulted in an error message along with success message.

- [CUI-2333]: Fixed an issue with the Check for Updates function while also doing a manual updateresulted in an internal server error.

- [CUI-2335]: Fixed an issue with default alerts for Application and SDC being created with Admin as the tagged creator.

- [CUI-2351]: Fixed an issue with log sorting. Now logs are displayed with the sequenced timestamp.

- [CUI-2387]: Fixed an issue with failure to create IDDM applications.

- [CUI-2392]: Fixed an issue with inconsistency in the Events filter.

## Security Vulnerability Fixes

- [CUI-2317, 2318]: Addressed CVE-2024-29409.

- [CUI-2360]: Fixed vulnerability on the current version of vite and vite react plugin.

- [CUI-2395, 2396]: Updated the version of the @nestjs/platform-express from 10.4.17 to 10.4.19 library to address CVE-2025-48997.
