# Environment Operations Center September 2025 Release Notes

September 30, 2025

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v1.5.0.
These release notes contain the following sections:

[New Features](#new-features)

[Improvements](#improvements)

[Bug Fixes](#bug-fixes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)


## New Features

- [CUI-2443]: Introduced Reporting capability enabling users to create, schedule, and manage reports derived from dashboards.

- [CUI-2063]: Introduced Identity Observability application to Environment Operations Center (EOC).

## Improvements

- [CUI-2430]: Improvement to display the "Created At" date and time in the Environment list, and to standardize the Secure Data Connector (SDC) search to be consistent with other EOC search bars.

- [CUI-2431]: Improvement to create a new Identity Data Management application by importing the configuration of an existing one, for better user experience.

- [CUI-2432]: Improvement to allow tenant admins to define retention policies for growing data types (Alerts, Events, Tasks, Notifications).

- [CUI-2441]: Improvement to add a Warning screen for the SDC, Users, and Authentication sections when passing empty values in the mandatory fields.

- [CUI-2469]: Improvement to update settings events and email notification descriptions to be more specific.

- [CUI-2468]: Improvement to remove the slash from end of LDAPS endpoint.

- [CUI-2473]: Improvement to set the Identity Data Management dashboard as the default dashboard for the IDDM Monitoring tab, and increase the monitoring Time Range to up to 1 year.

- [CUI-2476]: Improvement to display a Warning/Error message when deleting an Application in the case of that Application being used in the Promotion Pipeline.

- [CUI-2542]: Improvement to be able to backup and restore Identity Analytics and Identity Observability applications even when the application is offline.

## Bug Fixes

- [CUI-2433]: Fixed an issue where creating an Environment with an existing name and an additional character resulted in 400 Error.

- [CUI-2442]: Fixed an issue where the Environment Admin was unable to update the Security Settings.

- [CUI-2444]: Fixed Promotion Pipeline flow view inconsistencies.

- [CUI-2454]: Added a check while adding the environment to an existing Promotion Pipelines if that environment application has version update task running.

- [CUI-2494]: Fixed an issue where the Promotion Pipeline email notification didn't include the Pipeline name.

- [CUI-2499]: Fixed an issue with inconsistency in the Environment description when assigned to multiple roles.

- [CUI-2502]: Fixed an issue where users could not update the Default Alerts and Log Integrations.

For known issues reported after the release, please see the Radiant Logic Knowledge Base: 
https://support.radiantlogic.com/hc/en-us/categories/4412501931540-Known-Issues
