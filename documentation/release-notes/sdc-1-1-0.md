# Secure Data Connector Client v1.1.0 Release Notes

December 18, 2024

These release notes contain important information about improvements made to the Secure Data Connector Client v1.1.0.

## Improvements
* [AG-593]: Replaced unsigned binaries with signed binaries for enhanced security.
* [AG-597]: Improved error handling. Inlets client disconnect state is now handled as an error state within the SDC client.
