# Environment Operations Center February 2025 Release Notes

February 7, 2025

These release notes contain important information about new features, improvements and bug fixes for Environment Operations Center v1.3.0.

These release notes contain the following sections:

[New Features](#new-features)

[Improvements](#improvements)

[Bug Fixes](#Bug-fixes)

[Known Issues/Important Notes](#known-issuesimportant-notes)

[How to Report Problems and Provide Feedback](#how-to-report-problems-and-provide-feedback)

## New Features

- [CUI-1795]: Added functionalities for creating, deleting, and restoring both manual and scheduled backups for Identity Analytics.

- [CUI-1973]: Added an environment-level UI feature to configure IP address based access for Identity Data Management applications.

- [CUI-2029, CUI-2027]: Enabled users to integrate, configure, and push logs to log aggregators: Splunk, Sumo Logic, OpenSearch, and ElasticSearch. Enabled log retention policy to be set by the tenant admin, per log type, which applies across all environments in the tenant. For Identity Data Management applications v8.1.3 and above.

- [CUI-2030, CUI-2032]: Added maintenance notifications and details pages to enable users to be alerted to and see upcoming maintenance information.

- [CUI-2059, CUI-2076]: Enabled restore from backup functionality for Identity Data Management applications.

- [CUI-2110]: Added "Download Logs" functionality, for IDDM applications v8.1.3 and above. Removes the "View Logs" option from dropdown menu. 


## Improvements

- [AG-597]: Improvement to error handling. Inlets client disconnect state is now handled as error state in SDC client.

- [CUI-2042]: Added ability to edit descriptions for environments and applications.

- [CUI-2053]: Added additional properties to Webhook and Grafana integration.

- [CUI-2087]: Improved the display for Non Production and Production selections, gray tags for Non Production and green tags for Production.

- [CUI-2090]: Added "Created by <creator name>" to environments on the environment page.

- [CUI-2096]: Enabled users to define and set a new custom alert metric label manually.

- [CUI-2097]: Improvement to environment page to display avatar for environment creator instead of text.

- [CUI-2098]: Added ability to "favorite" environments on environments page and filter based on favorites.

- [CUI-2102]: Improvement to audit logs to display the IP address of the user's access point.

- [CUI-2107]: Improvement to readability of logs.

- [CUI-2118]: Improvement to limit the number of characters for the name of manual backups to 16 characters.

- [CUI-2120]: Improvement to be able to filter environments by creator.

- [CUI-2121]: Improvement to retain filters on environment page (such as selecting only IDDM environments) when navigating away and back to the environment page.

- [CUI-2123]: Added separate alert icons for IDDM & IDA applications for the notification to be filtered per application.

- [CUI-2147]: Improvement to limit the access/visibility of integrations to those created by the user. Non tenant admins can only see the alert/log integrations they have created along with the alert/log default integration. Note Tenant admins can see all alert/log integrations when they are creating alerts or selecting log integrations in log config.

## Bug Fixes

- [AG-593, SQT-307]: Fixed an issue related to Windows binary. Windows binaries package is now code signed with EV code signing certificate.

- [AG-617, SQ-228]: Fixed an issue related to SDC recovering after connection error.

- [CUI-2062]: Fixed an issue with users being able to assign an existing backup file name.

- [CUI-2068, SQ-208]: Fixed an issue with backup emails containing broken links. The link now redirects users to the specific backup page.

- [CUI-2091]: Fixed an issue related to user permissions, the environment user is now only able to view the details of the environment to which they are assigned.

- [CUI-2103]: Fixed an issue with previously created environments not being listed during SDC group creation.

- [CUI-2105]: Fixed an issue with default alerts and IDDM application being hidden.

- [CUI-2123]: Fixed an issue with backup complete emails being sent erroneously.

- [CUI-2125]: Fixed an issue with auto-update not checking for udpates as scheduled.

- [CUI-2128]: Fixed an issue where non-Admin users could click on the Admin tab.

- [CUI-2145]: Fixed an issue where IP CIDR value was persisting even after deleting and restarting.

- [CUI-2146]: Fixed an issue with filters being applied to Environments.

- [CUI-2148]: Changed how logging and monitoring being enabled/disabled is displayed and configured to be more clear and accessible.

- [CUI-2151]: Fixed an issue with pagination on View Schedule tab.
